### What Was Done Yesterday

**YouTube Audio Download — Permanent Fix (`src/transcription.py`):**
- **Bug:** "Requested format is not available" error recurring on certain YouTube URLs
- **Root cause:** Any `format` string (including `bestaudio*`) can fail because YouTube controls which formats are available per video
- **Fix:** Removed `format` key entirely from yt-dlp options; replaced pydub manual conversion with yt-dlp's built-in `FFmpegExtractAudio` postprocessor
- **Why permanent:** yt-dlp picks whatever YouTube offers, ffmpeg converts to mp3 — no format negotiation can fail
- **Requires app bounce** to take effect (module is cached on import)

```python
ydl_opts = {
    # No format selector — yt-dlp picks best available automatically
    'outtmpl': os.path.join(temp_dir, "temp_audio_for_transcription.%(ext)s"),
    'postprocessors': [{
        'key': 'FFmpegExtractAudio',
        'preferredcodec': 'mp3',
        'preferredquality': '192',
    }],
}
```
