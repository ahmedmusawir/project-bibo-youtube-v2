### [11:02am] — YouTube Audio Download: Permanent Fix

**User issue:** Same "Requested format is not available" error recurring on `https://www.youtube.com/watch?v=Mrsp9kdwFQs`

**Root cause of recurrence:** Previous fix used `'format': 'bestaudio*'` — still a format selector that can fail on certain videos depending on what YouTube makes available at that moment. Any format string can break on specific videos.

**Permanent fix in `src/transcription.py` — `_download_audio_to_temp()`:**

- **Removed `format` key entirely** — no format selector at all; yt-dlp picks the best available automatically
- **Replaced pydub manual conversion** with yt-dlp's built-in `FFmpegExtractAudio` postprocessor
- yt-dlp downloads whatever format YouTube offers, then ffmpeg converts it to mp3 192k internally
- Added leftover file cleanup before download (prevents stale file confusion)
- Added clear error message if ffmpeg is missing from PATH

**Why this is permanent:**
- yt-dlp's postprocessor approach works regardless of what formats YouTube provides
- ffmpeg handles conversion from any container/codec to mp3
- No format negotiation can fail because we never specify a format — yt-dlp always picks something

```python
ydl_opts = {
    # No format selector — yt-dlp picks best available automatically
    'outtmpl': os.path.join(temp_dir, "temp_audio_for_transcription.%(ext)s"),
    'postprocessors': [{
        'key': 'FFmpegExtractAudio',
        'preferredcodec': 'mp3',
        'preferredquality': '192',
    }],
}
```

**Prerequisite:** ffmpeg must be installed and in PATH (already required by moviepy for video composition anyway).
